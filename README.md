## ✨ Features
1. 👥 **Local Multiplayer:** Play against a friend on the same device.
2. 🎨 **Premium Aesthetics:** Features a dark glassmorphism UI, gradient elements, and an animated particle background.
3. 📐 **Customizable Grids:** Choose your battleground size: 3×3, 4×4, 5×5, or 6×6.
4. ✨ **Rich Animations:** Smooth hover effects, turn indicators, score popping, and a confetti victory modal.
5. 📱 **Fully Responsive:** Play comfortably on desktop or mobile devices with touch support.

## 🚀 How to Play
1. **Open** `index.html` in your web browser.
2. **Take turns** clicking/tapping the space between two adjacent dots to draw a line.
3. If your line completes a 1×1 square (box), it fills with your color, you score a point, and you **get another turn!**
4. The game ends when all boxes are claimed. The player with the most boxes wins.

## 🛠️ Built With
- `index.html`: Layout and semantic structure.
- `style.css`: Modern CSS with custom properties (variables) for theming.
- `game.js`: Canvas rendering, game state management, and interaction logic.
